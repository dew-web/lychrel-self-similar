# 自己相似な逆順加算サイクルと、9進法のリクレル数の族

逆順加算（x → x + reverse(x) を回文になるまで繰り返す、いわゆる「196問題」）についての研究コードとデータです。英語版: [README.md](README.md)

## 主な結果
1. **9進法のリクレル数の族**（調べた範囲では新しい）。m ≥ 2 に対し（9進表記）
   `N(m) = 1012563461128208006630705832188788502108582878207 [8がm個] 10581 [0がm個] 782087205811204808870238508037588811821254465208`
   に逆順加算を10回施すと正確に N(m+2) になり、途中に回文は現れない。よって N(m) はすべて9進のリクレル数。
   最小の N(2) は9進106桁（10進101桁）。定理・1周期の表・証明は [base9/RESULT.md](base9/RESULT.md)。
2. **探索手法。** 0 と B-1 の長い列が鏡像に並ぶ型（Seal・Brown型）の自己相似サイクルは、列が繰り上がり1ビットを素通しするだけなので有限の問題になる。
   端の文字列（`outauto`）と中心の文字列（`coreauto2`）を、どちらも長さ無制限で存在判定できる。2・4・11・26進の Seal の族を自動で再発見する。手法は [docs/METHOD.md](docs/METHOD.md)。
3. **10進法。** この型の自己相似サイクルは周期15以下に存在しない（文字列の長さは無制限）。周期16〜20も、状態数の上限を超えた2パターンを除いて存在しない。
   唯一の惜しい候補（周期11、両端各29桁が正確に閉じる）には、どの長さの中心も合わない。表は [results/SUMMARY.md](results/SUMMARY.md)。
4. **196の軌道**（[p196/](p196/)）。AVX2 で1コア約4分で100万桁に到達し、Walker の2,415,836回を再現。繰り上がりの統計と、停止確率の減衰率の解析。

## 使い方
```sh
make                 # bin/ にビルド
make verify-base9    # 短い確認（m=2..60）と、全ての m ≥ 2 についての記号計算による証明
make validate        # 2・4・11・26進の再発見と、9進の族の発見を再現（数分）
```
必要なもの: gcc と Python 3（標準ライブラリのみ）。p196 は AVX2 対応の x86-64 CPU が必要。

## 注意
- 9進の証明は計算機援用（m を記号のまま扱う厳密な有限計算）。`base9/symbolic_proof.py` を確認してほしい。
- 10進の分類は上記の型と周期の範囲に限る。中央に一様な列がある型は旧版でしか調べておらず、ここには含めていない。
- `outauto` の旧版には64ビットの状態キーが溢れるバグがあった。ここにある結果はすべて修正版（256ビット）によるもの。
- 9進の結果の新規性は、まだ専門家の確認を受けていない。
