# 繰り上がりの作用素と緩和の実験（carries/）

- `op.py` : Holte の繰り上がり行列の確認と、逆順加算の「良い対」の確率を繰り上がりまで含めて正確に数える転送作用素。
  状態は位置ごとに (列和 s_k, 下半分の繰り上がり L_k, 上半分の繰り上がり H_{k+1})（約 8B 次元）。最大固有値が減衰率 λ。
  `python3 carries/op.py`（全基数、数十秒） / `python3 carries/op.py --quick`（動作確認）
- `relaxlib.py` : 逆順加算の1ステップ（配列演算）と、W(j) の傾きから λ を出す関数。
- `relax_perstep.py` : 一様乱数から k=1..16 回の逆順加算をしたあとで、1回ごとに λ を測る（2のべき乗の「跳ね上がり」の確認用）。
- `relax_buckets.py` : 同じことを 1, 2, 3–4, …, 129–256 回の区間にまとめて測る。
- `results/` : 2026年11月のチャットでの実行結果（perstep_B*.txt, buckets_B*.txt, op_output.txt）。

主な結果（予備的）:
- 繰り上がり込みの作用素の λ は「1回だけ逆順加算した数」の実測と一致する（例: 10進 0.6565、16進 0.6491）。作用素には2のべき乗だけのずれはない。
- 2^b 進法では、乱数から b+2 回目あたりで λ が跳ね上がる（4進 4回目、8進 5回目、16進 6回目、32進 7回目、64進 7〜8回目）。2のべき乗でない基数は 3〜5 回で落ち着く。
