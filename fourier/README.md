# 逆順加算を波として見る（フーリエ・転送行列・減衰率の測定）

- `wave.py` : 逆順加算の1ステップ（NumPy、繰り上がりは「列和≥Bなら1・=B−1なら素通し」で一括計算）。
  実行すると、反転と周波数の恒等式、回文からの距離 A、転送行列の固有値と余弦波の固有ベクトルを確かめる。
- `lam.py` : 状態1（桁が増えた直後）の項で良い対の連続長を数え、W(j) の傾きから減衰率 λ を推定する関数 `measure(B, N)`。
- `lam_rep.py`, `lam_rep2.py` : 基数ごとに複数本の軌道で λ を測る。
- `verify2.py` : 19基数×3本の λ、推定方法の確認、履歴なしの対照、数字の分布 → `verify2.txt`
- `verify3.py` : 共有される数字の2つのコピーの一致率 F と、隣り合う対の相関。
- `results/` : 実行結果。

主な結果: 簡略モデルの減衰率は 1/(2B sin(π/(2(2B+1)))) → 2/π（固有ベクトルは余弦波）。
実際の軌道では9以上の2の冪以外の基数で 2/π ≈ 0.637 の近く、2の冪はモデルの値の近く（予備的）。
